# React 19 Concepts

An interactive educational application for learning React 19 and core React concepts through live, runnable demos. Built with Vite 6, React 19, and CSS Modules with SASS.

## Features

The app covers three main areas:

**React 19** — `use()` hook for promises and context, `useTransition` with async Actions, `useActionState` for form management, `useFormStatus` for descendant form state, `useOptimistic` for optimistic UI, `ref` as a regular prop (no more `forwardRef`), Context as direct provider (no `.Provider`), and native document metadata (`<title>`, `<meta>`, `<link>`).

**Classic Hooks** — All foundational React hooks from 16.8 with descriptions and code examples: `useState`, `useEffect`, `useRef`, `useContext`, `useReducer`, `useMemo`, `useCallback`, `useImperativeHandle`, `useLayoutEffect`, and `useDebugValue`.

**Reference** — Virtual DOM explanation with reconciliation walkthrough and a curated collection of common React interview questions across Core Concepts, Hooks, React 19, and Performance & Architecture.

## Tech Stack

- React 19
- Vite 6
- CSS Modules with SASS
- Dracula-themed syntax highlighting

## Install

```bash
npm install
```

## Usage

```bash
npm run dev
```

Open the URL shown in your terminal (default `http://localhost:5173`). Click any feature card to explore a concept with an interactive demo, explanation, and highlighted code example.

To create a production build:

```bash
npm run build
npm run preview
```
